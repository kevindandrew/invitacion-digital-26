# Canciones de la invitación

Copia aquí tus canciones para el reproductor de música que aparece en la invitación. No hay que tocar ningún código.

- Formato permitido: `.mp3`.
- El nombre del archivo se usa como título de la canción, así que nómbralo como quieras que se vea, por ejemplo: `Nuestra cancion.mp3`, `Segundo recuerdo.mp3`.
- Si quieres controlar el orden en que suenan, numera los archivos al inicio: `01 Nuestra cancion.mp3`, `02 Segundo recuerdo.mp3` (el número no se muestra en el título).
- Se recomienda que no pesen demasiado (idealmente menos de 8 MB cada una) para que la invitación cargue rápido.

Después de agregar tus archivos, corre `npm run dev` (o vuelve a desplegar el sitio) para escucharlas.
