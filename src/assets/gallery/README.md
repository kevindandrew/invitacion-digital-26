# Álbum de fotos

Esta carpeta es el "álbum" de la invitación. Todo lo que pongas aquí aparece automáticamente en la sección "Un día para volver a mirar" — no hay que tocar ningún código.

- Copia aquí tus fotos (hasta 80 o las que quieras).
- Formatos permitidos: `.jpg`, `.jpeg`, `.png`, `.webp`.
- Los nombres de archivo no importan, pero si quieres controlar el orden en que aparecen, nómbralas con números al inicio: `01-foto.jpg`, `02-foto.jpg`, `03-foto.jpg`, etc.
- Se recomienda que las fotos no pesen demasiado (idealmente menos de 2–3 MB cada una) para que la invitación cargue rápido. Si tus fotos son muy pesadas, puedes comprimirlas antes en una web como squoosh.app o tinypng.com.

Las fotos van apareciendo y desapareciendo en posiciones aleatorias, en un bucle continuo. Cada vez que una foto se desvanece, la reemplaza otra al azar del álbum.

Después de agregar tus archivos, corre `npm run dev` (o vuelve a desplegar el sitio) para verlos reflejados.
